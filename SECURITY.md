# Sécurité

## Signaler une vulnérabilité

Ne publiez pas de détails exploitables dans une issue publique. Utilisez le [signalement privé d'une vulnérabilité GitHub](../../security/advisories/new) pour contacter les responsables. Si cette option n'est pas disponible, ouvrez une issue sans détail sensible pour demander un moyen de contact privé.

Indiquez la version concernée, les étapes de reproduction, l'impact possible et, si possible, un exemple sans données personnelles. Les responsables examineront le signalement et conviendront avec vous d'une divulgation après correction. Aucune durée de réponse n'est garantie.

La dernière version publiée est la seule version suivie pour les correctifs de sécurité. MacClair n'a pas fait l'objet d'un audit indépendant : gardez une sauvegarde de vos données et vérifiez les fichiers avant de confirmer leur déplacement.
